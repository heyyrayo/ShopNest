# ShopNest AI Development Rules

Version 1.0

---

## Purpose

These rules apply to every AI coding assistant used in this project.

Examples:

- Codex
- Claude
- Bob
- Cursor
- GitHub Copilot
- Future AI tools

---

# General Rules

1. Never modify files unless they are explicitly listed.

2. Never create new files unless requested.

3. Never delete existing code without explaining why.

4. Never rename folders.

5. Never change routing without permission.

6. Never install new packages unless requested.

7. Never change project structure.

8. Always explain major architectural decisions.

9. Follow React best practices.

10. Use Tailwind CSS only.

11. Use reusable components.

12. Avoid duplicated JSX.

13. Prefer arrays + map() whenever appropriate.

14. Use semantic HTML.

15. Keep components modular.

16. Never generate unnecessary code.

17. Follow the existing folder structure.

18. Keep code readable.

19. Write production-quality code.

20. Preserve existing functionality.
